# Clinic Management System - Mfumo wa Usimamizi wa Kliniki

## Muhtasari (Overview)
Mfumo wa kisasa wa usimamizi wa kliniki unaoundwa kutoka kwa miundo minne muhimu:

### 1. **Reception Module** 📋
- Usajili wa wagonjwa mpya
- Kuhariri taarifa za wagonjwa
- Kuupdate profile wa mgonjwa
- Kumtuma mgonjwa kwa daktar
- Kuandika kumbukumbu ya mgonjwa

### 2. **Doctor Module** 👨‍⚕️
- Kupokea orodha ya wagonjwa kutoka reception
- Kuangalia historia ya mgonjwa
- Kuandika uchumi wa kitiba
- Kumtuma mgonjwa kwa maabara au famasi
- Kuandika kumbukumbu za tiba
- Kupokea matokeo kutoka maabara

### 3. **Lab Technician Module** 🔬
- Kupokea vipimo vya magonjwa kutoka daktar
- Kuandika matokeo ya vipimo
- Kurejesha matokeo kwa daktar
- Kuandika kumbukumbu za vipimo
- Kuandika historia ya vipimo

### 4. **Pharmacy Module** 💊
- Uhamiaji wa dawa kwenye hazina
- Kuandika hali ya dawa (stock levels)
- Kutoa dawa kwa wagonjwa
- Kuingiza dawa mpya
- Kuandika historia ya dawa
- Kuandika kumbukumbu za utendaji wa hazina

## Teknolohija (Technology Stack)
- **Frontend**: React.js / Vue.js
- **Backend**: Node.js / Python Flask
- **Database**: PostgreSQL / MongoDB
- **API**: RESTful API
- **UI**: Modern & Responsive Design
